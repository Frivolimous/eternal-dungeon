# Terminology

| Term | Meaning |
| --- | --- |
| Town | Reached at the end of each dungeon. Heroes rest and prepare here, and are picked for the next dungeon. Skill points are spent and respecced here, and the Secondary and Dabble picks are made here. Has the Tavern, shop and shared stash. |
| Dungeon 0 | The first-time tutorial dungeon, a shortened Goblin Woods. Played once per save, never by later heroes. |
| Map | One explorable area of a dungeon, Outdoor (forests, ruins) or Indoor (caves, castles; an indoor floor is a Map): a fog-of-war network of Nodes. A dungeon is one or more Maps. Replaces "Floor". |
| Node | One piece of explorable content on a Map. It can hold an Event and Interactables, and connects to other Nodes. Drawn as a Region (Outdoor) or a Room or Hallway (Indoor). |
| Region | How an Outdoor Map draws a Node; its Node type shows as a Feature (Forest Clearing, Goblin Village). |
| Room | How an Indoor Map draws a Node; it shows its Node type (Prison, Library, Boss Room). |
| Hallway | An Indoor Node type linking Rooms and other Hallways. A set share of Hallways hold a Hallway Event. |
| Event | A one-time sequence of blocks (story, choices, rolls, combat, rewards) triggered by exploring a Node. It ends closed or deferred. |
| Interactable | A lasting feature of a Node the player can use, possibly many times: Stairs, Pathway, Indoor Entrance, Sanctuary, Shop, Forge, Shrine. |
| Stamina | Per-hero endurance for a dungeon. Major and Boss fights cost 1. Below 0 a hero is Exhausted, at −4 Unconscious. Rest restores it. |
| Camp | Rest anywhere on a Map, using one of the party's Camp charges (1 per normal dungeon, 2 per large). Restores Stamina and part of Health and Mana. |
| Sanctuary | A single-use Interactable that fully restores Health and Mana and Rests the party. |
| Tag | A label on an action, such as Melee, Fire or Spell. Stats keyed to that tag affect every action carrying it. |
| Compound stat | A friendly stat, such as Strength or Dodge, that converts into tag stats through a fixed recipe. |
| Primary / Secondary / Dabble | A hero's three class layers: 5, 3 and 1 tree skills, and 3, 2 and 1 class traits. |
| Mastery | One of a class's 3 one-level abilities, unlocked in order at 1, 6 and 11 points spent in that class's tree. Active abilities come from masteries. |
| Trait | An out-of-combat quality (Military, Streetwise, Arcana…) that opens Event options. Classes, Talents and Races grant traits; the same trait twice raises its level. |
| Exploration skill | One special exploration rule per class; a hero has only its Primary class's. |
| Blessing | A strong bonus granted at a Temple. It's removed by a party wipe, and future Blessings weaken with each death and each repeated dungeon. |
| Boon | A temporary bonus that lasts for a set number of battles within a dungeon. |
| Trinket | A bonus that lasts for one dungeon run. Trinkets come in levels and tiers. |
| Artifact | A prestige item, unlocked by beating a dungeon's last level and equipped on Reincarnation. A hero can equip up to 3, and Artifacts level up to 10. |
| Reincarnation | Prestige reset of a hero. It fully restores Blessings, improves Artifacts and changes the hero's race. |
| Shadow World | The endless, unscripted bonus dungeon. |
| Tavern | Where new heroes are recruited. Each candidate has a fixed class, a race and random Talents. |
| Dungeon level | How far a hero has progressed. It rises when the hero takes part in completing a dungeon, and it decides which gear the hero can hold. |
| Death counter | Per hero, +1 for each party wipe. Each death weakens future Blessings by 5%. |
| Gear tier | 0–2, set by equipment type. Using gear above the hero's Primary+ count carries a weight penalty. |
