# Art requests

Generated by `sim art-requests` from the data: don't edit by hand. Every image the battle screen uses, per art style.

- A style is a folder `game/assets/styles/<style>/` holding these files as `<id>.png`, at exactly these sizes.
- Sizes are **2× the size on screen** at the 1280×800 reference layout, so art stays sharp on larger screens.
- No text in images: names, numbers, bars and icons are drawn by the game.
- Only portraits are needed to start; everything marked optional falls back to a generated placeholder, and a
  missing portrait does too (never a crash).
- AI-made placeholders: list the style in `game/assets/manifest.json` with `aiPlaceholder: true`.
- Masters can be any size: name each file by its id (`portrait_warrior.png`), put them in
  `art-source/<style>/` (not in git) and run `tools/resize-art.bat <style>`. It crops each from the centre
  to the right shape and resizes it to the exact size below. Frames need transparency (PNG or WebP).
